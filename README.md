##  Lancer le projet en local

Le portfolio est un site **100 % statique** (HTML + CSS + Bootstrap). Aucune installation n'est nécessaire.

### Option 1 — Ouvrir directement le fichier

Ouvrir le fichier `index.html` dans un navigateur (double-clic ou clic droit → "Ouvrir avec").

### Option 2 — Serveur local avec Python (recommandé)

```bash
# Se placer dans le dossier du projet
cd PORTFOLIO

# Lancer un serveur local
python -m http.server 5500
```

Puis ouvrir [http://localhost:5500](http://localhost:5500) dans le navigateur.

### Option 3 — Extension Live Server (VS Code)

1. Installer l'extension **Live Server** dans VS Code.
2. Ouvrir le dossier `PORTFOLIO` dans VS Code.
3. Clic droit sur `index.html` → **Open with Live Server**.
